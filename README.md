# linear-foundations
variables d'etat, modeles lineaires, statistiques, visualisation.

## Projets

- `breakeven/` — Seuil de rentabilite d'une application mobile
- `weighted-average/` — Moyenne ponderee et detection de risque academique
- `growth-models/` — Croissance lineaire, exponentielle et logistique
- `descriptive-stats/` — Statistiques descriptives implementees de zero
- `budget-forecast/` — Projection financiere et simulation de budget
